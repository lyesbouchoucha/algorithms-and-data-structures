## Problem Statement
A mergeable heap supports the following operations: `MAKE-HEAP` (which creates an empty mergeable heap), `INSERT`, `MINIMUM`, `EXTRACT-MIN`, and `UNION`. 

Show how to implement mergeable heaps using linked lists. Try to make each operation as efficient as possible.

## Complexity Achieved
* **MAKE-HEAP:** $O(1)$
* **INSERT:** $O(1)$
* **UNION:** $O(1)$
* **MINIMUM:** $O(n)$
* **EXTRACT-MIN:** $O(n)$
